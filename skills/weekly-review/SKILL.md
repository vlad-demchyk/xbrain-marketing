# Weekly review

Reply in the user's language. Read the product card (see `product-marketing`) and last week's
review if it exists (same place as the card, `reviews/YYYY-MM-DD.md`, or the brain's project notes).

## 1. Numbers by level

| Level | Metrics | Question |
|---|---|---|
| Attention | Watch time, completion, sends, saves, reach | Does the content stop people? |
| Interest | Profile visits, clicks, newsletter signups | Do they want more? |
| Action | Landing conversion, signups, activation | Does the promise hold? |
| Money | Payments, cost per acquisition, retention | Does it pay back? |

Ask only for what is missing; accept rough numbers and mark them. Compare with last week and, where
useful, with `marketing-benchmarks`.

## 2. What worked

The top 3 pieces of the week by the platform's own success metric (see `platform-pack`), and the
common thread between them (topic, format, hook, time). The bottom 3 and why.

## 3. Last week's hypothesis

Confirmed, refuted or inconclusive, with the numbers. Inconclusive is a valid answer; do not stretch
a small sample.

## 4. Next week

1. One hypothesis (see `funnel-audit` for the format).
2. The content plan: which ideas, on which platforms, in which format, what to double down on.
3. One thing to stop doing.

Save the review next to the card (or hand it over as Markdown in chat-only mode).

# Marketing benchmarks

The numbers live in [references/benchmarks-2026.md](references/benchmarks-2026.md). Read only the
section the task needs.

## Rules for using a number

- **Cite the source and the year** next to every figure you put in front of the user.
- **Compare within one source only.** Socialinsider measures engagement against followers, Buffer
  against reach: 0.48% and 5.5% for Instagram are both right and not comparable.
- **A benchmark is a direction, not a target.** The user's own baseline beats any industry median;
  when the user has data, compare against it first.
- **Vendor figures are leads.** Many "statistics" pages are written by agencies selling the thing
  they measure (UGC, influencers, GEO tools) and quote each other. Mark them as such.
- **Older than 12 months:** say the date. If `data_as_of` above is more than 6 months old, offer a
  refresh before relying on the numbers for a decision.

## Refreshing the data

When the user asks, or the data is stale and a decision depends on it:

1. Search for the newest edition of each source in the reference file (Buffer State of Social Media
   Engagement, Socialinsider benchmarks, Unbounce Conversion Benchmark, ChartMogul/ProductLed SaaS
   benchmarks, IAB creator economy, Gartner and Edelman trust surveys, platform earnings for user
   counts, GEO studies by Ahrefs, Semrush, Muck Rack).
2. Prefer primary pages (the publisher's own report or press release) over roundups.
3. Update the figures, the source line and the date in the reference file, and `data_as_of` above.
   Keep a removed figure in the "Retired" section with why it went.
4. Tell the user what changed and which conclusions in the other skills it affects.

Without file access, give the user the updated section as Markdown to replace.
